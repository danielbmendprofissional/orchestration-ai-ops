# `glab` (CLI do GitLab) — procedimento do agente

```powershell
winget install GLab.GLab
```

Autenticação abre navegador → **parar aqui**, pedir pro humano rodar `glab auth login` e escolher `gitlab.com` + "Login with a web browser" (ou colar um personal access token). Confirmar depois: `glab auth status`.
